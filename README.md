# Employee Management System

A Spring Boot REST API for managing employees.

## Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- SQL Server
- Maven
- Lombok

## Features
- Create Employee
- Get All Employees
- Get Employee by ID
- Update Employee
- Delete Employee

## Upcoming Features
- Bean Validation
- DTO Pattern
- Global Exception Handling
- Pagination & Sorting
- Search API
- Spring Security & JWT
